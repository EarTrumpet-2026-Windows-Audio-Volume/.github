# Project Overview

EarTrumpet is a Windows audio utility designed to provide more detailed control over application and device volume directly from the system tray.

It extends the standard Windows volume experience with a dedicated mixer that allows users to control individual application volumes, switch audio output devices, and manage common sound settings without opening the full Windows Settings application.

EarTrumpet is particularly useful for systems with multiple applications and audio devices, such as headphones, speakers, monitors, USB audio interfaces, and Bluetooth devices.

---

# Application Volume Mixer

EarTrumpet provides individual volume controls for applications currently producing or using audio.

Instead of changing the system volume for every application simultaneously, users can adjust applications independently. This can be useful when listening to music while playing games, watching videos, participating in calls, or using other applications with different volume requirements.

The mixer can be accessed directly from the Windows notification area for quick adjustments.

---

# Audio Output & Input Devices

EarTrumpet provides convenient controls for switching between available Windows audio devices.

Users can select different output devices such as speakers, headphones, monitors, USB DACs, and Bluetooth audio devices when supported by Windows.

The application can also expose per-application routing options, allowing supported applications to use a different audio output device from the Windows default.

---

# Windows Integration & Customization

EarTrumpet is designed to integrate naturally with the Windows desktop and system tray.

The application provides a modern interface while maintaining quick access to commonly used audio controls.

Users can configure available settings and customize aspects of how EarTrumpet behaves within Windows. It can also be configured to launch automatically when Windows starts.

EarTrumpet uses Windows audio APIs rather than replacing the operating system's underlying audio system.

# Accessibility & Keyboard Control

EarTrumpet supports keyboard-oriented workflows and Windows accessibility features.

Its mixer provides an alternative interface for controlling audio levels without repeatedly navigating through Windows Settings.

Keyboard shortcuts and supported system controls can make frequently used volume operations easier to access, depending on the Windows version and configured options.
